# Week 3 – ML Fundamentals (AnalystLab Africa Internship)

## Overview
This week focused on core machine learning concepts: the difference between supervised and unsupervised learning, proper train/test splitting, overfitting vs underfitting, and model evaluation. Concepts were applied using the Iris and Titanic datasets.

## Contents
- `IrisAnalystLabAfricaWeek3.ipynb` – Classification work on the Iris dataset
- `TitanicAnalystlabWeek3.ipynb` – Classification work on the Titanic dataset

## Topics Covered
- **Supervised vs Unsupervised Learning**: Understanding labeled vs unlabeled data problems
- **Train/Test Splitting**: Why models must be evaluated on unseen data
- **Overfitting vs Underfitting**: Balancing model complexity to generalize well
- **Model Evaluation**: Using metrics beyond raw accuracy to judge performance

## Key Takeaway
A model's training accuracy alone doesn't confirm it works. Test performance and proper evaluation are what actually validate a model.

## Tools Used
Python, scikit-learn, pandas, Jupyter Notebook
